# AI 图像生成与工具导航

分享开源图像生成项目，供学习交流与技术参考；收录优质 AI 工具、AI 生图和 AI 生视频工具，方便查找与使用。

[AI 工具](#ai-工具) · [AI 生图](#ai-生图) · [AI 生视频](#ai-生视频) · [开源项目学习](#开源项目学习)

## AI 工具

查资料、写内容、整理信息与辅助编程。

| 工具 | 简介 |
| --- | --- |
| [ChatGPT](https://chatgpt.com/) | 通过对话完成问答、写作、资料整理、文件分析和代码编写。 |
| [DeepSeek](https://www.deepseek.com/) | 支持中文问答、推理和代码生成，帮助梳理思路、理解问题与辅助开发。 |
| [Perplexity](https://www.perplexity.ai/) | 搜索并整理网页信息，回答问题时提供来源链接，便于查阅和核实。 |
| [Cursor](https://cursor.com/) | 在代码编辑器中使用 AI，理解项目、编写代码、修改功能与排查错误。 |

## AI 生图

生成和编辑图片，探索创意、设计与视觉表达。

| 工具 | 简介 |
| --- | --- |
| [Midjourney](https://www.midjourney.com/) | 根据文字描述生成图片，用于插画创作、概念设计和视觉风格探索。 |
| [Gemini 图像生成](https://gemini.google/overview/image-generation/) | 通过对话生成图片，或上传参考图，按文字指令调整画面。 |
| [稿定 AI](https://www.gaoding.com/ai) | 结合 AI 图片创作与在线设计，制作海报、电商图片和社交媒体素材。 |
| [Craiyon](https://www.craiyon.com/) | 输入文字生成图片，探索照片、插画、动漫等不同视觉风格。 |

## AI 生视频

通过文字或图片创作视频，制作镜头与短片。

| 工具 | 简介 |
| --- | --- |
| [Runway](https://runwayml.com/) | 通过文字或图片生成视频，并提供视频编辑功能，辅助镜头和短片创作。 |
| [可灵 AI](https://klingai.kuaishou.com/) | 快手推出的 AI 视频创作工具，支持根据文字描述或参考图片生成视频。 |
| [通义万相](https://wan.video/) | 阿里推出的 AI 视觉创作平台，支持文字生成视频、图片生成视频和图像创作。 |
