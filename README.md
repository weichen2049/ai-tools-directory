# AI 图像生成与工具导航

开源图像生成项目，汇集优质 AI 工具、AI 生图与 AI 生视频工具。

[AI 工具](#ai-工具) · [AI 生图](#ai-生图) · [AI 生视频](#ai-生视频)

## AI 工具

用于日常问答、信息搜索、内容写作和编程开发。

| 工具 | 能做什么 |
| --- | --- |
| [ChatGPT](https://chatgpt.com/) | 对话式 AI 助手，可用于写作改稿、整理资料、分析文件和编写代码。 |
| [DeepSeek](https://www.deepseek.com/) | 支持中文对话、推理和代码生成，可用于解答问题、梳理思路和辅助开发。 |
| [Perplexity](https://www.perplexity.ai/) | 用自然语言搜索资料，汇总网页信息并附上来源，方便继续阅读和核查。 |
| [Cursor](https://cursor.com/) | 在代码编辑器中使用 AI，理解项目、生成代码、修改功能和排查错误。 |

## AI 生图

用文字和参考图创作图片，制作插画、海报与营销素材。

| 工具 | 能做什么 |
| --- | --- |
| [Midjourney](https://www.midjourney.com/) | 根据文字描述生成图像，可用于插画、概念设计和视觉风格探索。 |
| [Gemini 图像生成](https://gemini.google/overview/image-generation/) | 在对话中生成和修改图片，支持上传参考图并用文字描述修改要求。 |
| [稿定 AI](https://www.gaoding.com/ai) | 将 AI 图片创作与在线设计结合，用于制作海报、电商图片和社交媒体素材。 |
| [Craiyon](https://www.craiyon.com/) | 根据文字描述生成图片，可尝试照片、插画、动漫等不同风格。 |

## AI 生视频

把文字或图片变成视频，辅助镜头创作与短片制作。

| 工具 | 能做什么 |
| --- | --- |
| [Runway](https://runwayml.com/) | 通过文字或图片生成视频，并提供视频编辑工具，辅助镜头设计和短片制作。 |
| [可灵 AI](https://klingai.kuaishou.com/) | 快手推出的 AI 视频创作平台，可通过文字描述或参考图片生成视频。 |
| [通义万相](https://wan.video/) | 阿里推出的 AI 视觉创作平台，支持文生视频、图生视频和图像生成。 |

## 推荐工具与纠错

发现值得收录的工具，或遇到链接失效、介绍有误，欢迎[提交 Issue](https://github.com/weichen2049/ai-tools-directory/issues)。请附上工具名称、官网链接和简短说明。

## 开源生图项目

想搭建自己的生图网站，可以查看仓库中的 [Imago 源码](examples/imago)。这是一个基于 Next.js 的开源 AI 创作项目，包含图片与视频生成、用户登录、积分支付和历史记录模块。运行配置见[中文说明](examples/imago/docs/setup_zh.md)。

源码来自 [tenngoxars/Imago](https://github.com/tenngoxars/Imago)，保留上游 [MIT 许可证](examples/imago/LICENSE)。固定版本及文件校验信息见[来源记录](examples/imago.upstream.json)。
