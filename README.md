## 收录原则

- 面向普通用户可使用的产品，优先选择功能清楚、质量稳定、官网可访问的工具。
- 每个工具写明适用场景、推荐理由、价格类型与核验日期。
- 免费、中文、开源作为筛选属性，不重复建立一级分类。
- 一个产品维护一条记录，可标记多个能力；不为扩大数量重复收录。
- 赞助或关联推广需明确标注；不以付费代替质量审核。

分类及后续产品记录保存在 [data/catalog.json](data/catalog.json)。

## 开源生图网站示例

[examples/imago](examples/imago) 保存 [tenngoxars/Imago](https://github.com/tenngoxars/Imago) 的源码副本，上游提交为 `cdf7591a920d2c6dc1b01fe9cc31d01cc01af0ac`。

Imago 使用 Next.js，包含生图、视频、用户、积分支付和历史记录等模块。它是独立示例，并非导航目录的运行依赖，也不代表本目录已上线生图服务。

本仓库仅完成源码复制与文件一致性检查，尚未安装依赖、运行应用或验证生成及支付功能。正式运行需要核对模型 API 适配、Supabase、Stripe 和对象存储配置；开源代码不包含免费的模型算力或服务额度。
